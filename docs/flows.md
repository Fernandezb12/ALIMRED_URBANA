# Flujos clave

## Flujo principal (demo)
1. Usuario inicia sesión.
2. Donante registra donación.
3. Organización registra solicitud.
4. Admin ajusta prioridad.
5. Admin crea asignación donación → solicitud.
6. Estado cambia y se refleja en dashboard + historial.

## Flujos secundarios
- Actualización de estado de donaciones y solicitudes.
- Consulta de trazabilidad en historial.
- Edición de datos básicos de perfil.
