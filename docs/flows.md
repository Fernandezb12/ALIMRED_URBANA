# Flujos clave

## Flujo principal (demo)
1. Usuario inicia sesión.
2. Según rol entra a `/panel` con KPIs y accesos segmentados.
3. Donante registra donación / Organización registra solicitud.
4. Admin prioriza y crea asignación.
5. Estados y trazabilidad se actualizan en tiempo real.

## Flujo de mapa
1. Cualquier rol habilitado abre `/mapa`.
2. Visualiza puntos de Neiva por tipo (donación, solicitud, entrega, organización).
3. Filtra categorías para soportar el pitch de impacto territorial.
